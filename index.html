Meridian – Automated Portfolio & Wealth Management System

Modello finanziario avanzato su foglio di calcolo (Excel / LibreOffice Calc) per il monitoraggio e l'asset allocation di un portafoglio investimenti multi-asset.

  • Architettura Finanziaria & Contabile: Modellazione relazionale (Securities Ledger, Trade Timeline, Cash Flows) per il tracciamento granulare del capitale e netta separazione tra Total Cost, Realized P/L e flussi di cassa.
  • Asset Allocation & Target: Monitoraggio dinamico degli scostamenti dai target di allocazione e calcolo automatico delle metriche di performance.
  • Consolidamento Multi-Owner: Infrastruttura logica per aggregare l'asset allocation a livello di nucleo familiare, calcolando quote di proprietà e performance dei singoli membri.
Excel / LibreOffice Calc Multi-Asset Engine Asset Allocation

python-xls-price-loader – Portfolio Price Engine for Excel

Engine in Python sviluppato per interfacciare fogli di calcolo finanziari (come Meridian) con flussi dati di mercato in tempo reale ed esportazione web.

  • Data Pipeline & Market API: Estrazione automatizzata dei prezzi di mercato live via yfinance per asset globali.
  • Excel Automation: Scrittura programmatica e aggiornamento automatico delle celle di Meridian tramite la libreria openpyxl.
  • Dashboard HTML Standalone: Generazione dinamica di una dashboard web (HTML/CSS/JS) interattiva con grafici di performance ed esportazione snapshot CSV.
Python (yfinance/openpyxl) ETL Pipeline

bitcoin-mnemonic-tx-checker – Mnemonic & On-Chain Scanner

Script Python per la generazione di seed mnemonic Bitcoin e la scansione automatizzata delle transazioni on-chain per indirizzi derivati.

  • BIP39 Seed Generation: Generazione di frasi mnemoniche e calcolo dei relativi percorsi di derivazione gerarchica.
  • On-Chain API Querying: Scansione della storia delle transazioni e verifica automatica dei bilanci associati agli indirizzi derivati.
  • Audit & Security Tooling: Utility utile per l'esplorazione autonoma e l'analisi di indirizzi e privacy on-chain.
Python BIP39 / BIP32 On-Chain Scanner
GitHub Repo ↗

bip32-extpriv-recovery – Cryptographic Key Recovery Tool

Utility Python per il recupero di una Extended Private Key (xprv) radice a partire da una chiave privata figlia non-hardened, la xpub genitore e l'indice di derivazione.

  • Dimostrazione Pratica di Rischio: Implementazione dell'attacco crittografico matematico legato all'esposizione congiunta di una xpub e una chiave privata non-hardened.
  • Ricostruzione Algoritmica: Calcolo inverso basato sulla matematica delle curve ellittiche per ricavare la xprv.
  • Protocol Security Audit: Sviluppato a scopo educativo e di sicurezza per evidenziare l'importanza dell'uso di derivazioni hardened.
Python BIP32 Elliptic Curves Key Security

Zenith 1.1 – Personal Finance Accounting System

Modello contabile avanzato su foglio di calcolo per il monitoraggio integrato dei flussi di cassa familiari, patrimonio netto (Net Worth) e gestione multi-conto.

  • Architettura a 6 Vettori Logici: Tracciamento tramite Income, Outflow, Investment, Self Transfer, Transit, Info per isolare le uscite reali e gestire rimborsi e transiti.
  • Balance Control Table: Riconciliazione automatica in tempo reale con i saldi reali degli estratti conto bancari.
  • Financial Reporting: Dashboard basata su formule condizionali (SOMMA.PIÙ.SE) per il calcolo automatizzato di Gross e Net Outflow.
LibreOffice Calc Multi-Account Engine Accounting Architecture

ColdMobile – Dispositivo di Firma Offline Air-Gapped

Guida tecnica e architettura per trasformare uno smartphone dismesso in un dispositivo di firma affidabile, completamente isolato da qualsiasi rete.

  • Isolamento hardware e software totale da connessioni internet/wireless.
  • Comunicazione bidirezionale basata esclusivamente sul passaggio di codici QR.
  • Focus su self-custody resiliente, riduzione della fiducia ed eliminazione di single points of failure.
